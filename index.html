FAQ · trust

Answers first

How is this different from CoSeat / SeatBadlo / Swapr / XchangeSeat / GoodSeat?

Those apps tell you “Side Upper”. SwapSeat draws the coach: which bay, which side, which level, how far the walk is. Flight cabins show exits, wings, lavs — from the airline's aircraft type.

Where do train / flight layouts come from?

Train number → coach composition table (js/data.js, extend with live IR / UIC APIs). Flight number → airline + aircraft → cabin template (A320neo, 737, 787…). Plug real APIs later; maps already render from data.

Is swapping legal? Do crew approve?

Consensual swaps coordinated with TTE / cabin crew are normal. Crew have final authority, especially exit rows & 1A cabins.

How does money work?

Posting a swap is free (1/mo). Requesters can pay ₹19 instant-reveal or ₹29 boost; helpers earn credits. Plus (₹99/mo) = unlimited + priority. No money changes hands for the seat itself.

Does it work offline / as an app?

Yes — installable PWA. Maps + your requests cached by the service worker; works in tunnels & flight mode.
