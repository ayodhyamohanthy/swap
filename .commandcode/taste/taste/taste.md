# Taste
- Drives long-running builds with terse one-word directives ("continue", "resume", "retry") rather than restating requirements; expects the agent to re-derive the current state from the repo (git status/diff, docs, build plan) and decide the next step autonomously — including re-reading shared coordination files that may have changed underneath it. Confidence: 0.75
- Wants full execution autonomy: "auto approve all you need, not ask permissions" — proceed straight through destructive or long-running actions (commits, editing shared coordination files, running dev-server scripts, long test suites) without pausing for confirmation; treat a tool/permission prompt as friction to avoid, not a safety check to honour — restated again as a bare `cmd --yolo` invocation, so this is the standing default rather than a one-session exception. Confidence: 0.85
- Expects a running project's source of truth to live in-repo as versioned documents/designs plus a build plan, and wants implementation resumed from those artifacts rather than from chat memory. Confidence: 0.55
- Works in shared repos where several agents commit concurrently, and stands up explicit collab machinery for it (lane/surface ownership files, a pre-commit guard that rejects out-of-scope or hot files). Expects an agent to stay inside its claimed file scope, stage nothing it does not own (`git commit --only -- <own paths>`, never a blanket `git add -A`), name the owner in any claim line so tooling can recognise it, and file cross-lane follow-ups in the shared board instead of editing another lane's files. Confidence: 0.5
- Treats finished work as something to land promptly, not leave in the working tree: uncommitted changes in a shared tree get swept into someone else's commit, so behavior changes should be committed with the tests that pin them, and attribution of any already-swept pieces stated in the commit message. Confidence: 0.45
- Works in an uncommitted, in-progress state and expects the agent to re-establish a green baseline (typecheck + test suite) before adding new features. Confidence: 0.5
- Layers verification rather than trusting one gate: fast lane-scoped tests for feedback, then the full suite (run sequentially when a build step regenerates files the tests read), then a real-browser smoke pass over newly added routes to catch things unit gates miss, e.g. a route that registers but renders an empty outlet. Confidence: 0.45
- Distinguishes its own failures from pre-existing ones before reacting: a red baseline or a red file owned by another lane is documented and reported to that lane, not silently fixed and not treated as grounds to stop shipping. Confidence: 0.45
- Targets mobile-first PWAs as the delivery form for the products they build (stated as the goal of the build, not a native app). Confidence: 0.6
- Prefers UI that renders nothing over UI that guesses: when the data does not support a headline, count, or label (a family split across two trains, passengers with no berth allotted yet), omit the element rather than showing the first record's value. Confidence: 0.45
- When a structured spec and a design mockup disagree, follows the spec for per-screen/structured data and the mockup for layout and wording, then files the conflict for reconciliation instead of silently picking one. Confidence: 0.45
- Prefers deriving shared values once in a library function that several screens call, rather than duplicating the derivation per screen; and reusing existing i18n keys (including translated-but-unused copy) over introducing new strings. Confidence: 0.45
- Comments are for the *why*, written for the next agent: they cite the governing doc/design id, state the invariant or failure mode the code prevents, and call out near-miss lookalikes that must not be merged or "simplified" back. Confidence: 0.45
- Pins behavior with tests aimed at the failure mode, and adds structural guard tests that read the source tree to enforce invariants no type or unit test catches — a route has a real entry point outside its own flow, navigation uses the router rather than `window.location`, chrome matches spec. Confidence: 0.4
