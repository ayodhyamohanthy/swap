## The finding: 54 of 121 `app/src` files are owned by no lane

`deadSurfaces` (built 2026-10-01) catches a surface that matches no file. Nobody
had counted the complement — **a file no surface matches** — and it is 45 % of
the app. Method: `parseSurfaces` + `ownedByLane` from `lane-board.mjs` imported
unchanged, over `git ls-files app/src`. Reusing the module rather than
reimplementing the glob is what makes the census and the guard unable to
disagree about what "owned" means.

By directory: `lib/` 22, `routes/` 21, `components/` 5, `server/` 3, plus
`routeTree.gen.ts`, `router.tsx`, `worker.ts`.

**An unowned file is permissive, not dangerous** — `clashesFor` only refuses a
file some surface *matches*, so nobody is blocked, and two lanes editing one
file are not stopped either. The cost is the one L1 named: the next lane to
touch it has no claim to check against.
