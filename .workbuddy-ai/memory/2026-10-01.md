## The harness discipline, again

Same shape as the backup-contract work, and it earned its place again:

1. **Assert the baseline is GREEN first.** A red baseline makes every "caught"
   mutation meaningless.
2. **Assert the mutation APPLIED** before asserting it was caught.
3. **Include a negative control** that must stay silent, or the harness is only
   proving it can shout.
4. **Verify the file is restored byte-identical** (SHA-256) at the end.

Results: CLI 5/5 caught, tests 3/3 caught, 0 missed, 0 harness-broken, one
negative control silent, `docs/13` restored byte-identical.

The negative control mattered: an assertion of **emptiness** (`expect(dead).toEqual([])`)
passes just as happily when the thing measured is empty. If `sourceFiles()` had
returned `[]`, every new test would have been green and worthless.

## Traps hit this session

- **BSD grep: `\|` is not alternation in BRE.** Hit it three times. `grep -E` or
  separate patterns.
- **BSD grep: `\s` and `\b` are unsupported in ERE.** Use `[[:space:]]`.
  `grep -cE "^\|\s*L[0-9]"` returned **0** on a file with 10 matching lines.
- **`import.meta.url` is not a `file:` URL under the jsdom pool.**
  `fileURLToPath(new URL('../../', import.meta.url))` throws
  "The URL must be of scheme file" **at collection time** — the whole file fails
  with `(0 test)`, which reads like a broken test file, not a broken assumption.
  The repo's idiom is **`import.meta.dirname`**.
- **`npx tsc --noEmit` from the repo ROOT prints help text and exits 0.**
  `tsconfig.json` is in `app/`; the real gate is `npm run typecheck`.
