## 6. Measurement traps hit in this pass

1. **`stat -f '%Sm' -t '…Z'` prints LOCAL time.** `-t` sets the display format only;
   it does not convert the timezone. A file written at `14:57Z` printed as
   `20:27:35Z` on a `+0530` machine — reading as 5½ hours in the future when the
   claim was 7 minutes old. Use `stat -f '%m'` (epoch) or the raw `+0530` offset.
2. **`--strictPort` means your server did not start.** A port collision made my dev
   server exit while a neighbour's kept answering, so a `curl` health check passed
   against a process I did not own. `lsof -a -p <pid> -d cwd` is the check.
3. **Substring scans measure the wrong thing.** `if base in text` reported `app.js`,
   `auth.js`, `data.js`, `i18n.js` as referenced by `index.html` — every hit was the
   *suffix* of `seatswap-app.js`, `seatswap-auth.js`, `seatswap-data.js`,
   `seatswap-i18n.js`. Anchored with `(?<![\w.-])name\b`, the count is zero.
4. **BSD `grep` has no `\b`.** `grep -rInE -i '\bpush\b' docs/` returned **nothing**
   for a word present in seven files. Third spelling of this trap, after `\|` in BRE
   and `find -newermt`.
5. **A slow run is not a hang.** The suite took **9m00s against a ~3m30s baseline**
   (`environment 892s`) because `~/Tools/swap` — a **different repo**, `HEAD
   ae2ffd1`, no `docs/14-LANES.md` — was running its own `vite dev`. Load, not a hang.
